# 图片资源优化清单

图片往往是页面体积的最大来源，优先级高于 JavaScript 优化。

## 格式选择

照片类用 WebP 或 AVIF，图标用 SVG，避免用位图承载图形。

## 尺寸与响应式

按显示尺寸生成多档位图片，配合 srcset 让浏览器挑合适的一档，避免把 4K 图缩成 100px 展示。

## 加载策略

首屏外图片全部懒加载，首屏关键图预加载；占位图要固定宽高，避免累积布局偏移。

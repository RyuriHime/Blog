# 构建工具与打包优化

打包产物的体积直接决定首屏渲染时间，因此构建阶段的优化通常收益最大。

## 代码分割

把路由级代码拆成独立 chunk，配合按需加载，能显著降低首屏需要下载的 JavaScript 体积。

## 依赖体积分析

用打包分析工具找出体积最大的依赖，常见做法是替换重型库、开启 tree shaking、
把只在特定页面用到的依赖改成动态 import。

## 构建缓存

持久化构建缓存可以让二次构建从分钟级降到秒级，具体见 [CI 流水线配置](./ci-pipeline.md)。

## 与性能指标的配合

构建优化最终要落到性能指标上，做法见 [前端性能优化实践指南](./seed-performance.md)。

# HTTP 缓存策略详解

缓存是成本最低的性能优化：命中缓存就不需要重新下载资源。

## 强缓存与协商缓存

强缓存用 Cache-Control 控制，协商缓存依赖 ETag 与 Last-Modified。
静态资源通常配长强缓存加内容哈希文件名，HTML 用协商缓存保证及时更新。

## CDN

把静态资源放到 CDN 能同时降低延迟和源站压力。注意缓存键要包含内容哈希，否则发布新版本会出现混用。

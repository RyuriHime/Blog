# 导数与积分：从变化率到累积量

## 一、导数：刻画"瞬间的变化"

设函数 $f(x)$ 在点 $x_0$ 的某个邻域内有定义。若极限

$$
f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}
$$

存在，则称 $f$ 在 $x_0$ 处可导，该极限称为 $f$ 在 $x_0$ 处的导数。

导数回答的是"此刻变化得多快"：位移对时间的导数是速度，速度对时间的导数是加速度。

### 1.1 常见导数

| 函数 | 导数 | 备注 |
| --- | --- | --- |
| $x^n$ | $n x^{n-1}$ | 幂法则，$n \neq 0$ |
| $\sin x$ | $\cos x$ | 周期不变 |
| $e^x$ | $e^x$ | 唯一等于自身导数的函数 |
| $\ln x$ | $1/x$ | 定义域 $x > 0$ |

### 1.2 求导法则

- **乘积法则**：$(uv)' = u'v + uv'$
- **商法则**：$\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$
- **链式法则**：$\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}$

链式法则是复合函数求导的全部秘密。把 $y = \sin(2x)$ 看成 $y = \sin u$、$u = 2x$，
就有 $y' = \cos u \cdot 2 = 2\cos(2x)$。

## 二、积分：把无穷小累加起来

不定积分是求导的逆运算：

$$
\int f(x)\,dx = F(x) + C, \qquad F'(x) = f(x)
$$

定积分则给出"曲线下的面积"：

$$
\int_a^b f(x)\,dx = F(b) - F(a)
$$

这个等式就是**微积分基本定理**：求导与积分互为逆运算，把两个看起来无关的问题
（切线斜率、曲边梯形面积）缝在了一起。

### 2.1 一个可以手算的例子

$$
\int_0^1 x^2\,dx = \left[\frac{x^3}{3}\right]_0^1 = \frac{1}{3}
$$

把 $[0,1]$ 分成 $n$ 份做黎曼和，得到 $\frac{1}{n^3}\sum_{k=1}^{n} k^2 = \frac{(n+1)(2n+1)}{6n^2}$，
令 $n \to \infty$ 就得到 $\frac{1}{3}$。

### 2.2 数值验证

理论上 $f'(x) = 2x$，用中心差商可以在代码里验证：

```js
function derivative(f, x, h = 1e-6) {
  return (f(x + h) - f(x - h)) / (2 * h);
}

const f = (x) => x * x;
console.log(derivative(f, 3)); // ≈ 6
```

注意 $h$ 不能太小：浮点数的舍入误差会让差商反而变差，
实践中 $h \approx 10^{-6}$ 左右比较稳。

## 三、两者为什么会互相抵消

微积分基本定理的直观解释：

1. 把 $[a, b]$ 切成很多小段，每一段的"面积"近似是 $f(x)\,\Delta x$；
2. $f(x)\,\Delta x \approx \Delta F$，也就是原函数在这一小段上的增量；
3. 把所有增量加起来，中间的项全部两两抵消，只剩 $F(b) - F(a)$。

所以积分是"把变化率重新拼回总量"，求导是"从总量里取出变化率"。

## 四、常见误区

- 把 $\dfrac{d}{dx}$ 当成一个可以随便约分的分数 —— 它是算子，不是除法。
- 忘记不定积分的 $+C$：少了它，答案只对了一个特例。
- 认为可导必连续、连续必可导 —— 前者成立，后者不成立（$|x|$ 在 $0$ 处连续但不可导）。
- 混淆"函数在某点可导"与"导函数在该点连续"：后者需要额外条件。

## 五、练习

1. 求 $f(x) = x^3 - 3x + 1$ 的极值点，并说明它是极大还是极小。
2. 计算 $\displaystyle\int_1^e \frac{1}{x}\,dx$。
3. 用链式法则求 $\dfrac{d}{dx}\left[\ln(\sin x)\right]$。

> 提示：第 1 题先求导、令导数为零，再用二阶导数判断符号；
> 第 2 题的答案恰好是 1，这也是 $e$ 的一个常见定义方式。
